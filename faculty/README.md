# Faculty Guide
Use this repo in two ways:
1. **Live demonstrations** (`demos/`): short, scripted walkthroughs that show real-world AI system design in class.
2. **Student projects** (`student-projects/`): students build their own zone in phases, each ending in a pass/fail gate.

The architecture doc explains the "why", and the starter shows the "how". Students change `zone.yaml`, `schema/`, the seed data, and `zone-mcp`, and they leave the standard components alone.
